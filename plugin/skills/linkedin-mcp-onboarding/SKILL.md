# Onboarding workflow

Find the existing repository and inspect its `AGENTS.md`, `docs/STATUS.md`, and `plans/EXECUTION_PLAN.md`. Do not assume new plugin installation creates the application. Run the current offline tests; summarize granted scope vs implemented capability; do not post externally. If `GET /v2/me` is still 403, label author identity as blocked. Recommend Gate A, not a broad code-generation pass.
